2. Escopo do MVP (Artefato 6)

Login; cadastro com time de coração; post em texto; feed; like; comentário; ranking de torcida; resumo do dia; chatbot de jogos; cadastro de jogos pelo admin. Sem stories e sem API externa na banca.

3. Status desta entrega

O código do MVP será desenvolvido nas semanas de outubro, conforme o cronograma da disciplina. Este documento fixa a arquitetura para o grupo não divergir na implementação. Os protótipos da Entrega 4 já representam as telas que o React deve reproduzir.
